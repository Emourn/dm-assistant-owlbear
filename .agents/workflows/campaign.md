# Campaign Content Workflow

**This workflow applies whenever the user asks for ANYTHING related to their D&D campaign.**

## Step 1: Read the Campaign Rules
// turbo
Read `CAMPAIGN_RULES.md` in the project root. This file tells you:
- What sources to read and in what order
- What rules from Fixing Vecna are non-negotiable
- Where every source file is located

## Step 2: Read Fixing Vecna
// turbo
Read `campaign-material/extracted-text/Fixing Vecna.txt` — the ENTIRE document. This is the campaign's holy bible. Every piece of campaign content you write must align with this document.

## Step 3: Read the Campaign Frame
// turbo
Read the Campaign Frame at:
`C:\Users\carlo\.gemini\antigravity\brain\c4d248a0-4757-4022-af8f-908d5d8c93e0\campaign_frame_fixing_vecna.md`

## Step 4: Read the PC Backstory Bible (if PCs are involved)
// turbo
Read `campaign-material/pc_backstory_bible.md` — contains all four PCs' backstories, NPC connections, level-by-level integration beats, and the Hidden Web (DM-facing connections between PCs).

## Step 5: Read the relevant sourcebook text (if a specific adventure/location is involved)
// turbo
Based on the user's request, read the relevant file from `campaign-material/extracted-text/`:
- **Death House** → `Death House.txt`
- **Barovia / Strahd** → `Curse of Strahd.txt`
- **Eve of Ruin chapters** → `Eve of Ruin.txt`
- **Feywild / Witchlight / Zybilna** → `The Wild Beyond the Witchlight.txt`
- **Tomb of Horrors** → `Tales from the Yawning Portal.txt`

## Step 6: Read the relevant D&D 2024 rules (if mechanics are involved)
// turbo
Based on the user's request, read the relevant file from `extracted-2024-rules/`:
- **Classes, races, spells, feats** → `Players Guide (2024).txt`
- **Encounter design, magic items, DM tools** → `Dungeon Masters Guide (2024).txt`
- **Monster stat blocks** → `Monster Manual (2024).txt`

## Step 7: Write the content
Now — and ONLY now — write whatever the user asked for. Your content must:
- Align with Fixing Vecna's rules (no secrets mechanic, no Kas-as-Mordenkainen, etc.)
- Reference the correct NPCs and their characterization from the PC Backstory Bible
- Use D&D 2024 rules for any mechanics
- Match the tone described in the Campaign Frame for the relevant level range
