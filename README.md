# DM Assistant

This repository contains the standalone DM Assistant app and an Owlbear Rodeo extension build.

Useful entry points:

- Main app: `index.html`
- Owlbear popover: `owlbear.html`
- Owlbear workbench modal: `owlbear-workbench.html`
- Owlbear background page: `owlbear-background.html`

Build output for Owlbear:

- `dist/owlbear-manifest.json`

Extension packaging notes live in [OWLBEAR_EXTENSION.md](./OWLBEAR_EXTENSION.md).
